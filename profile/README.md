# exclnt

> Build. Learn. Share. Grow.

**exclnt** is a developer community focused on building software, exploring technology, sharing knowledge, and growing together.

We create and experiment with software through open-source projects, developer tools, web applications, and collaborative learning.

## What We Do

* Build open-source projects
* Explore modern technologies
* Develop useful developer tools
* Share knowledge and development practices
* Collaborate on real-world projects
* Learn through building

## Areas

`Web Development` · `Backend` · `Frontend` · `Full-stack` · `DevOps` · `Open Source` · `Developer Tools`

## Contributing

Everyone is welcome to learn, contribute, and collaborate.

You can contribute by:

* Reporting bugs
* Proposing ideas
* Improving documentation
* Opening pull requests
* Sharing knowledge
* Building projects together

Check each repository for its contribution guidelines.

## Community

**Learn openly.**

**Build together.**

**Share knowledge.**

**Keep improving.**
