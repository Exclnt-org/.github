# exclnt

**Build. Learn. Share. Grow.**

`exclnt` adalah komunitas dan ruang kolaborasi bagi developer untuk belajar, membangun, berbagi pengetahuan, dan berkembang bersama melalui teknologi.

## About

`exclnt` berfokus pada pengembangan software dan eksplorasi teknologi melalui project nyata, open source, eksperimen, serta kolaborasi antar developer.

Kami percaya bahwa menjadi developer bukan hanya tentang menulis kode, tetapi juga tentang memahami masalah, membangun solusi, berbagi pengetahuan, dan terus berkembang.

## What We Do

* Membangun project open source
* Mengembangkan aplikasi dan developer tools
* Eksplorasi teknologi baru
* Berbagi pengetahuan dan pengalaman
* Berdiskusi mengenai software development
* Berkolaborasi dalam project
* Menerapkan praktik development yang baik

## Contributing

`exclnt` terbuka terhadap kontribusi dari developer dengan berbagai tingkat pengalaman.

Beberapa cara untuk berkontribusi:

* Melaporkan bug
* Mengusulkan fitur
* Memperbaiki dokumentasi
* Membuat pull request
* Menambahkan atau memperbaiki testing
* Memberikan feedback
* Berkolaborasi dalam pengembangan project

Setiap repository dapat memiliki aturan kontribusi masing-masing. Silakan membaca `CONTRIBUTING.md` jika tersedia.

## Community Principles

### Learn Openly

Tidak masalah jika belum mengetahui sesuatu. Yang penting adalah kemauan untuk belajar.

### Build Together

Software yang baik dapat dibangun melalui kolaborasi dan pertukaran ide.

### Share Knowledge

Pengetahuan menjadi lebih bermanfaat ketika dibagikan kepada orang lain.

### Respect Others

Setiap developer memiliki pengalaman, latar belakang, dan cara belajar yang berbeda.

### Keep Improving

Tidak harus langsung sempurna. Yang penting terus belajar, memperbaiki, dan berkembang.
